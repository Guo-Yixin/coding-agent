# 标题关键字搜索技术方案（taskboard-title-search）

## 1. 需求理解

`search_tasks(tasks, query)` 需要实现「标题关键字搜索」，具体语义：

| 需求点 | 期望行为 |
| --- | --- |
| 忽略大小写 | `"api"` 能匹配 `"Fix API timeout"`，`"API"` 也能匹配 `"api docs"` |
| 保留输入顺序 | 结果按 `tasks` 中的原始先后顺序返回，不做重排 |
| query 为空时返回全部任务 | `""` 或 `None`/空值时返回所有任务（等价于不过滤） |
| 没有 title 的任务不报错、不误匹配 | `{"id": 1}` 这类任务既不抛异常，也不能被任何非空 query 命中 |
| 返回类型 | `list[Task]`，元素是原 dict 引用，不做拷贝（与现有风格一致） |

只修改 `taskboard/tasks.py` 与 `tests/test_search_tasks.py`，不动 `filter_by_status`、`sort_by_priority` 及它们的测试。

- 接口签名不变：`search_tasks(tasks: Iterable[Task], query: str) -> list[Task]`。

## 4. 具体实施步骤

### 步骤 1：修改 `taskboard/tasks.py` 的 `search_tasks`

保持现有结构，仅补齐大小写归一化：

1. 保留 `rows = list(tasks)`，先物化输入，保证结果顺序与输入一致且可重复遍历。
2. 空值短路：`if not query: return rows`（覆盖 `""` 与 `None`）。归一化只在短路之后做，避免 `None` 调 `.lower()` 报错。
3. 计算 `needle = str(query).strip().lower()`，冒号后统一小写。
4. 列表推导：取 `title = task.get("title")`，当 title 为空值（`None`/缺失/空串）时直接跳过；否则 `str(title).lower()` 后判断 `needle in haystack`。
5. 更新 docstring，把三点语义写清楚。

核心逻辑伪代码（不贴完整实现）：

```
rows = list(tasks)
if not query: return rows
needle = str(query).strip().lower()
result = []
for task in rows:
    title = task.get("title")
    if not title: continue            # 缺失 / None / 空串都不参与匹配
    if needle in str(title).lower(): result.append(task)
return result
```

> 说明：用 `str(...)` 包裹是为了防止 title 是非法类型（例如 `{"title": 123}`）时抛 `AttributeError`，与现有实现习惯保持一致。

| 风险 / 待确认点 | 说明 | 建议 |
