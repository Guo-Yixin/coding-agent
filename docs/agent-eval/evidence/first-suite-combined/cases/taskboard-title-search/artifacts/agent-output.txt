# 标题关键字搜索（search_tasks）技术方案

## 1. 需求理解

用户目标是让 `taskboard/tasks.py` 中的 `search_tasks` 支持“标题关键字搜索”，边界条件如下：

| 需求点 | 语义 | 现状（已核实） |
| --- | --- | --- |
| 忽略大小写 | 关键字大小写不敏感，`api` 能命中 `API`、`Api` | 当前为 `query in task.get("title", "")` 的精确区分大小写匹配，不满足 |
| 保留输入顺序 | 命中结果按输入 `tasks` 的原始顺序返回，不做重排 | 目前用列表推导天然保序，但前提是能命中，修复时必须保持 |
| query 为空时返回全部 | `""`（以及无异常语义上的空值）返回全部任务 | 已实现 `if not query: return rows`，需保持不变 |
| 无 `title` 不报错、不误匹配 | 缺少 `title` 键的任务既不抛异常，也不能被当成命中项 | 已用 `task.get("title", "")` 规避 KeyError，需在忽略大小写后依旧成立并补测试 |

已核实的现场情况：

- 仓库 `https://github.com/Guo-Yixin/test-coding-eval`，当前分支 `main`，工作区仅有未跟踪的 `.codegraph/`，无文件改动。
- 定位结果（`hybrid_code_search`）：实现位于 `taskboard/tasks.py` 第 19–25 行的 `search_tasks(tasks: Iterable[Task], query: str) -> list[Task]`；导出见 `taskboard/__init__.py`；测试位于 `tests/test_search_tasks.py`、`tests/test_baseline.py`。

- 另有 `tests/test_filter_by_status.py` 与 `tests/test_sort_by_priority.py` 各 1 个失败，属于**其它 case 的范围**（`cases/README.md` 中 `taskboard-status-filter`、`taskboard-priority-aliases`），本次不修改。

- **行为契约（实施后应满足）**：
  1. 匹配语义：大小写不敏感的子串包含匹配，匹配对象是 `task["title"]` 的字符串形式。

## 4. 具体实施步骤

**步骤 1：修改 `taskboard/tasks.py` 的 `search_tasks`（仅这一处逻辑）**

- 保留早返回分支：`""`（假值）时直接返回 `list(tasks)`，保证“空查询返回全部且不突变输入”。
- 将匹配表达式改为“两侧都做小写归一化后的子串包含”：

  ```python
  needle = query.lower()                       # 或 query.casefold()
  return [task for task in rows
          if needle in str(task.get("title") or "").lower()]
  ```

- 关键点：内层用 `task.get("title") or ""`（而不是 `task.get("title", "")`），这样 `title` 为 `None` 时不会因 `str(None) == "None"` 而在搜索 `none` 时产生误匹配；同时对缺失键安全。
- 保持 `rows = list(tasks)` 与列表推导，保证顺序稳定、输入不被修改。
- 备注（需用户确认，见第 6 节）：`query.lower()` 对非 `str` 入参会抛错，沿用现有注释中的 `query: str` 契约；是否额外防御由用户决定。

**步骤 2：调整 `tests/test_search_tasks.py`**

## 二、修改内容

### 1. `taskboard/tasks.py`（唯一实现改动，3 行）

```python
rows = list(tasks)
if not query:
    return rows
needle = query.lower()
return [task for task in rows if needle in str(task.get("title") or "").lower()]
```

- `query.lower()` + `title.lower()`：双向大小写不敏感。
- `task.get("title") or ""`：缺 `title` 键不抛 `KeyError`；`title=None` 归一化为空串，不会因 `str(None) == "None"` 在搜索 `none` 时误匹配。
- `rows = list(tasks)` + 列表推导：保持原 `Iterable` 输入顺序、不修改入参、返回原 dict 引用。
- 空 query 早返回分支保留不变。
- `filter_by_status`、`sort_by_priority` 未改动。
