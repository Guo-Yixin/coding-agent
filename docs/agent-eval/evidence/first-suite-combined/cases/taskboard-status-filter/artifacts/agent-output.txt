# 状态筛选修复技术方案（taskboard-status-filter）

## 1. 需求理解

`hybrid_code_search` 已定位到实现位于 `taskboard/tasks.py:10-16`，签名如下：

```python
filter_by_status(tasks: Iterable[Task], status: str | None = None) -> list[Task]
```

当前实现存在三个语义缺陷：

| 现状 | 期望行为 |
| --- | --- |
| `task.get("status") == status`，严格区分大小写，`filter_by_status(tasks, "Open")` 无法匹配 `"open"` / `"OPEN"` | status 比较忽略大小写，两侧都归一化（如统一 `casefold()`） |
| `status is None` 直接 `return rows`，行为本身正确 | 必须保持：`status is None` 返回全部任务，且返回的是输入元素的浅拷贝列表 |
| 无匹配返回 `[]`，行为正确 | 保持：无匹配返回空列表，不抛异常 |

不变式约束（关键）：
- **不修改输入列表**：不调用 `tasks.sort()` / `append` / `remove`，切片与列表推导都可接受。
- **不修改任务对象**：禁止为归一化而写回 `task["status"]`，禁止 `copy` 后再改字段，禁止返回可能使调用方误解为可写的同一对象集合。
- 返回顺序必须与输入顺序一致（保持稳定，不做排序）。
- 仅允许修改 `taskboard/tasks.py` 和 `tests/test_filter_by_status.py`。

## 2. 涉及模块和需要阅读的文件

| 文件 | 作用 | 是否修改 |
| --- | --- | --- |
| `taskboard/tasks.py` | 存放 `filter_by_status` / `search_tasks` / `sort_by_priority` | 是（仅 `filter_by_status`） |
| `tests/test_filter_by_status.py` | 目标测试文件 | 是 |
| `taskboard/__init__.py` | 导出 `filter_by_status`，签名与行为契约不变 | 否 |
| `tests/test_baseline.py` | 基线测试，含 `filter_by_status(TASKS) == TASKS` 与输入不变断言 | 否（作为回归约束） |
| `pyproject.toml` | pytest 配置：`testpaths = ["tests"]`，`addopts = "-ra"`，`requires-python >= 3.11` | 否 |

补充说明：`tests/test_search_tasks.py`、`tests/test_sort_by_priority.py` 当前也处于失败状态，但那属于 `search_tasks`（大小写不敏感搜索）与 `sort_by_priority`（别名与稳定性）另外两个尚未实现的 case。本方案**不处理**它们，也不得为了让测试变绿而改动这两个模块。

## 3. 数据结构、接口或页面变化

- **无接口变更**：`filter_by_status` 的函数名、参数名、参数类型注解和返回类型 `list[Task]` 全部保持不变，`taskboard/__init__.py` 的 `__all__` 无需调整。
- **`Task = dict[str, Any]` 保持原样**，本次不引入 dataclass、TypedDict 或新增字段。
- **语义契约（写进 docstring 即可）**：
  1. status 为 `None` → 返回输入中的全部任务，保持原顺序；
  2. status 非 `None` → 返回 `status` 归一化后相等的任务，比较忽略大小写；
  3. 输入序列和其中的 `dict` 均不被修改；
  4. 返回新列表，元素仍为原 `dict` 引用（浅拷贝语义，与 `test_baseline.py` 的相等断言兼容）。
- 非字符串 status（如 `"OPEN"` 与 `123`）不做额外强转要求，仅对字符串用 `casefold()`；任务对象中缺失 `status` 键或 status 值非字符串时不得抛异常。

### `taskboard/tasks.py`（`filter_by_status`，+10/-2）

```python
def filter_by_status(tasks: Iterable[Task], status: str | None = None) -> list[Task]:
    """Return tasks matching status, comparing case-insensitively.

    ``status=None`` returns every task. Input order is preserved, the input
    sequence and its task mappings are never modified, and a new list is
    returned.
    """

    rows = list(tasks)
    if status is None:
        return rows
    target = str(status).casefold()
    return [task for task in rows if str(task.get("status", "")).casefold() == target]
```
