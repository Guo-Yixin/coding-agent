# 技术方案：实现 `group_tasks_by_status`

## 1. 需求理解

在 `taskboard` 包中实现公开 API `group_tasks_by_status(tasks)`：

- **解析产物**：`dict[str, list[Task]]`，键为归一化后的状态名，值为该状态下保持输入顺序的任务列表。
- **归一化规则**：状态值做去首尾空白 + `lower()` 处理；`status` 缺失、`None`、以及归一化后为空字符串的情况统一归入 `"unknown"`。
- **分组顺序**：不做状态名排序，按每个（归一化）状态在输入中**首次出现**的顺序确定插入顺序。
- **组内顺序**：保持输入相对顺序（Python `dict` + 追加即可天然满足）。
- **不修改输入**：函数只遍历 `tasks`，不就地修改任务字典，也不改变传入序列本身。
- **导出要求**：通过 `taskboard` 包顶层导出（`from taskboard import group_tasks_by_status` 可用）。
- **改动范围限定**：仅改动 `taskboard/tasks.py`、`tests/test_group_tasks_by_status.py`（如需确认导出，也只涉及 `taskboard/__init__.py` 的读取核对，不新增改动）。

```python
def group_tasks_by_status(tasks: Iterable[Task]) -> dict[str, list[Task]]:
    """Group tasks by normalized status, preserving first-seen group and row order."""

    groups: dict[str, list[Task]] = {}
    for task in list(tasks):
        raw_status = task.get("status")
        key = "unknown" if raw_status is None else str(raw_status).strip().lower()
        if not key:
            key = "unknown"
        groups.setdefault(key, []).append(task)
    return groups
```

要点：`list(tasks)` 物化以兼容元组/生成器；`strip().lower()` 归一化；缺失、`None`、空白字符串统一为 `"unknown"`；`dict.setdefault` 保证按首次出现顺序建组且组内保持输入顺序；只读原任务对象，不就地修改输入。

**2. `tests/test_group_tasks_by_status.py`** —— 保留原用例，新增 5 个用例（共 6 个）：
